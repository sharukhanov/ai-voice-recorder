# Исследование диктофона AIREC

## Устройство
- AliExpress: ALiandream «Цифровой диктофон», вариант «NEW AI VOICE RECORDER», 16 ГБ
  https://aliexpress.ru/item/1005009304093292.html
- Форм-фактор «карточка» 86×55×3.5 мм, OEM-устройство (вероятно, продаётся под разными брендами)
- Родное приложение: **AIREC** (AIREC LLC)
  - Android: `com.record.airec.google`
  - iOS: есть в App Store
- Передача записей на телефон — по Bluetooth (скорее всего BLE). Транскрипция/саммари — вероятно, в облаке производителя.

## Окружение пользователя
- Телефон: iPhone
- Компьютер: MacBook Air (Apple Silicon)

## Цель
Своё приложение, которое забирает записи с диктофона и делает нормальную
транскрипцию/саммари (облачный «ИИ» производителя заменяем своим).

## План разбора протокола
1. [ ] Проверить USB: виден ли диктофон как флешка (USB Mass Storage) и в каком формате файлы.
2. [ ] BLE-скан с Mac (`bleak`): имя устройства, сервисы, характеристики, их свойства.
3. [ ] Декомпиляция APK (`jadx`): UUID, команды, формат пакетов, кодек аудио, API-серверы.
   - Скачать APK из облачного контейнера не удалось (APKPure → 403), нужно скачать вручную в браузере.
4. [ ] Снять трафик родного приложения iPhone ↔ диктофон через PacketLogger
   (Xcode Additional Tools + профиль Bluetooth logging от Apple на iPhone).
5. [ ] Написать PoC на Python: подключиться, получить список файлов, скачать запись, декодировать аудио.
6. [ ] Решить стек приложения (iOS: Swift/CoreBluetooth или Flutter) и пайплайн ИИ (Whisper/LLM).
